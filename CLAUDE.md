# CLAUDE.md

Projektweite Anweisungen für Claude Code in diesem Repository.

## Sprache — verbindlich

**Antworte IMMER auf Deutsch.** Ausnahmslos, in jeder Session, in jedem
Verzeichnis dieses Repositories.

Gilt für:

- Chat-Antworten, Erklärungen, Zusammenfassungen und Rückfragen an den Nutzer
- Commit-Messages, PR-Titel und PR-Beschreibungen
- Review-Kommentare und Statusmeldungen auf GitHub
- Neue Dokumentation, sofern nicht ausdrücklich anders gefordert

Nicht übersetzt werden:

- Technische Bezeichner: Code, Dateinamen, Pfade, Befehle, API- und Feldnamen
- Bestehende englische Inhalte in diesem Repository (README, Specs, Code-Kommentare)
  werden nicht nachträglich übersetzt, solange niemand ausdrücklich darum bittet.
- UI-Texte einer Anwendung folgen der jeweiligen Produktsprache.

Auch wenn der Nutzer eine Frage auf Englisch stellt, bleibt die Antwort deutsch.

## Pull Requests — verbindlich

**Lege für abgeschlossene Arbeit immer einen Pull Request an**, ohne vorher zu
fragen. Sobald ein Feature-Branch fertig ist und gepusht wurde, folgt der PR.

- Titel und Beschreibung auf Deutsch (siehe Abschnitt Sprache).
- `.github/pull_request_template.md` als Gliederung übernehmen und ausfüllen.
- Checklistenpunkte nur abhaken, wenn sie tatsächlich geprüft wurden. Punkte,
  die für die Änderung nicht gelten, ausdrücklich als nicht zutreffend
  kennzeichnen statt sie stillschweigend abzuhaken.

Ausnahme: Der Nutzer sagt für eine konkrete Aufgabe ausdrücklich, dass kein
Pull Request gewünscht ist.
