# ProjectAtlas Desktop 0.2.2

## Sichtbarer Fortschritt beim Verbinden

Beim Einrichten („KI-Werkzeuge verbinden") lief der Index-Scan bisher ohne
Rückmeldung — das Fenster wirkte eingefroren. Jetzt zeigt der Dialog während des
Verbindens einen laufenden Fortschrittsbalken und eine hochzählende
Sekundenanzeige. Bei „Alle verbinden" markiert ein blinkendes Zeichen zusätzlich
das gerade laufende Projekt. Gilt für einzelne wie für alle Projekte.
